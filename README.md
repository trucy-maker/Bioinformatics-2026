# Máster en Bioinformática

¡Hola! Este repositorio contiene proyectos realizados durante mi Máster en Bioinformática (VIU).

## Proyectos

* RNAseq_Mammary_Gland_Mouse --> Pipeline completo (Bash y R) para el preprocesamiento de lecturas crudas, obtención de recuentos génicos, análisis de expresión diferencial (edgeR/limma) y ontología génica (topGO) en glándulas mamarias de ratón.*
* TFM_Epilepsia_RNAseq --> Pipeline en R (DESeq2 y limma/goana) para la caracterización transcriptómica de la zona epileptogénica frente a tejido sano a partir de muestras de sEEG, incluyendo memoria completa del TFM.*
